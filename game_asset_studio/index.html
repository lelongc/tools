HƯỚNG DẪN QUY TRÌNH TẠO ASSET & ANIMATION GAME VỚI AI

Quy trình hoàn chỉnh từ Prompt ➔ Video/Ảnh AI ➔ Tách nền tự động ➔ Xuất sang Godot
BƯỚC 1

Tạo Dáng Nhân Vật Ban Đầu Trên Phông Xanh (Green Screen)

Dùng ChatGPT / Midjourney tạo 1 ảnh nhân vật góc nhìn ngang (Side-view) đứng chính giữa trên nền xanh lá cây.

Prompt mẫu: "2D side-view character pose of a cartoon hero, centered, clean outlines, solid bright green chroma key background --ar 1:1"
BƯỚC 2

Tạo Video Chuyển Động (Image-to-Video - I2V)

Truy cập Tencent AI Studio (HY Video 1.5 I2V) hoặc Kling AI / Runway / Luma / HaiLuo:

  • Nạp ảnh nhân vật phông xanh vừa tạo ở Bước 1 vào mục Image-to-Video.
  • Nhập prompt: Full body character run cycle, fixed side profile view, running to the right, solid green screen background
  • Tải file video MP4 (dài khoảng 2–3 giây) về máy tính.
BƯỚC 3

Kéo Thả Video Vào Tab 2 ("Xử Lý Video AI")

Tool sẽ thay thế hoàn toàn Blender để tự động xử lý chỉ trong 1 nốt nhạc:

  • Tự Xóa Phông Xanh: Chọn 🟢 Phông Xanh Lá ➔ Tool tự bóc tách nền trong suốt 100%.
  • Cắt Chu Kỳ Loop: Chỉnh thanh Start (s) và End (s) (thường từ 0.2s đến 1.0s là vừa tròn 1 bước chạy).
  • Chọn Số Frame: Bấm chọn 8 Frame (hoặc 6, 10, 12 frame) ➔ Bấm ⚡ Bóc Tách Frame Ngay.
BƯỚC 4

Nạp Vào Studio & Xuất Sang Godot

Bấm nút ✨ Nạp Frame → Studio ➔ Xem trước chuyển động tại Tab 4 ➔ Bấm 🚀 Xuất Godot để tạo file SpriteFrames (.tres) tự động!

ẢNH SHEET

Dành Cho Vật Phẩm, Icon, Tileset Gạch Nền & Môi Trường

Đối với các asset tĩnh hoặc ít chuyển động (bình thuốc, vũ khí, rương báu, gạch nền sàn đấu):

  • Dùng ChatGPT / Midjourney tạo ảnh Spritesheet dạng lưới (2x2, 2x4 hoặc 4x4) trên nền trong suốt hoặc phông trơn.
  • Kéo thả ảnh vào Tab 3 (Cắt Ảnh Sheet).
  • Chỉnh số Cột/Dòng ➔ Bấm ⚡ Chia Lưới ➔ Dùng các nút 🦶 Căn Đáy, 🎯 Căn Giữa X, 📐 Đồng Bộ Cỡ để căn chuẩn pixel.
TỪ KHÓA

Bộ Từ Khóa "Vàng" Để AI Sinh Asset Game 2D Chuẩn Xác Nhất

solid bright green screen background: Phông xanh lá cây để tách nền 100%.
fixed side profile view: Khóa góc nhìn ngang chuẩn 2D, tránh AI xoay camera.
8-frame seamless loop: Chuyển động lặp mượt mà không bị khựng.
16-bit pixel art style, crisp outlines: Giữ viền nét chuẩn pixel retro.
running in place (run cycle): Chạy tại chỗ để bóc sprite.
modular seamless repeatable tileset: Gạch nền ghép nối liền mạch không lộ vết cắt.
GODOT 4

Cách Dùng Asset Đã Xuất Trong Dự Án Godot (d:\folder\tools\godot_demo\2\)

  • Khi bấm 🚀 Xuất Godot trong tool, toàn bộ file PNG và file .tres sẽ được lưu vào: res://assets/sprites/characters/<tên_nhân_vật>/.
  • Trong Godot, mở Scene nhân vật (ví dụ Player2D.tscn).
  • Chọn Node AnimatedSprite2D ➔ Kéo thả file <tên>_frames.tres vào mục Sprite Frames ở khung Inspector bên phải.
  • Chọn Animation cần phát (run, idle, attack) ➔ Bấm Play để chạy game!
