# Egg Destroyer 2D Game Asset Icon Pack (Godot 4 Ready)

Bộ Icon Vector SVG chuẩn dành cho Game "Thả trứng gà phá hủy công trình" trên Godot 4.

## Danh sách Icons:
### 1. Hệ thống Âm thanh & Cài đặt:
- `btn_sound_on.svg`: Bật hiệu ứng âm thanh (SFX)
- `btn_sound_off.svg`: Tắt âm thanh (SFX Mute)
- `btn_music_on.svg`: Bật nhạc nền (BGM)
- `btn_music_off.svg`: Tắt nhạc nền (BGM Mute)
- `btn_settings.svg`: Cài đặt / Tùy chọn

### 2. Điều hướng & Giao diện (UI Navigation):
- `btn_play.svg`: Nút Bắt đầu chơi (Play)
- `btn_pause.svg`: Nút Tạm dừng (Pause)
- `btn_replay.svg`: Nút Chơi lại / Thử lại màn (Retry/Restart)
- `btn_home.svg`: Nút Về Menu chính (Home)
- `btn_next.svg`: Nút Qua màn tiếp theo (Next Level)
- `btn_close.svg`: Nút Thoát / Đóng popup (Close / Exit)
- `btn_level_select.svg`: Nút Danh sách màn chơi (Level Select)

### 3. Gameplay & Chủ đề Phá Hủy (Egg & Siege Theme):
- `icon_egg_normal.svg`: Trứng gà thường (Đạn rơi cơ bản)
- `icon_egg_bomb.svg`: Trứng nổ TNT (Phát nổ diện rộng phá hủy thành trì)
- `icon_egg_golden.svg`: Trứng vàng (Điểm cao / Sát thương cực lớn)
- `icon_target.svg`: Hồng tâm ngắm thả trứng (Crosshair)
- `icon_star.svg`: Đánh giá sao qua màn (1 - 3 sao)
- `icon_tnt_box.svg`: Thùng nổ TNT / Công trình địch
- `icon_coin.svg`: Tiền thưởng / Vàng
- `icon_heart.svg`: Mạng sống / Lượt thả trứng

## Hướng dẫn sử dụng trong Godot 4:
1. Giải nén thư mục `egg_destroyer_ui_icons` vào thư mục dự án: `res://assets/icons/`.
2. Godot 4 tự động render SVG sắc nét ở mọi độ phân giải màn hình mobile.
3. Kéo thả file SVG vào thuộc tính `Texture Normal`, `Texture Pressed` của node `TextureButton` hoặc `texture` của `TextureRect`/`Sprite2D`.
