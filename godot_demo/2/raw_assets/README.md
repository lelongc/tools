# 📁 THƯ MỤC LƯU TRỮ TÀI NGUYÊN THÔ (AI RAW ASSETS)

Nơi lưu trữ an toàn các file ảnh và video gốc vừa tải từ AI về:
- ideos/: Chứa các video MP4 (2-3s) phông xanh tạo từ Tencent HY Video, Kling, Runway...
- images/: Chứa các ảnh phông xanh gốc tạo từ ChatGPT, Midjourney, DALL-E...
- udio/: Chứa các file âm thanh, nhạc nền raw.

*Lưu ý: Thư mục này có file .gdignore nên Godot sẽ không quét các file thô này vào game, giúp dự án luôn nhẹ và sạch.*
