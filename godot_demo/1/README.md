# 🌌 NEON WRONG WAY 3D — Commercial Game Package

**NEON WRONG WAY 3D** is a complete, production-ready, multiplayer & single-player 3D Cyberpunk party game built with **Godot 4.7+**. It features a unique "Control Chaos / Key Shuffling" mechanic, 5 diverse game modes, 8 Cyber Grid maps, cute blob character customization, and zero-dependency procedural synth sound engine.

## 📦 How to Build & Export

### 1. Requirements
- **Godot Engine**: v4.7.1 Stable (or compatible Godot 4.x release).
- Operating System: Windows 10/11 (macOS / Linux supported via Godot export).

### 2. Exporting Executable (`.exe`)
Run the following command from your terminal:
```powershell
godot --headless --export-release "Windows Desktop" ./bin/NeonWrongWay.exe
```
Or open the project in Godot Editor, navigate to **Project -> Export**, select **Windows Desktop**, and click **Export Project**.
