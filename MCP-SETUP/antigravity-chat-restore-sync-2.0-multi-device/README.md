## 📁 Danh sách tệp tin trong thư mục:

1. **[HUONG_DAN_REMOTE_ANTIGRAVITY_DIEN_THOAI.md](file:///d:/folder/tools/MCP-SETUP/antigravity-chat-restore-sync-2.0-multi-device/HUONG_DAN_REMOTE_ANTIGRAVITY_DIEN_THOAI.md)**:
   - 📱 **Hướng dẫn chi tiết từng bước** để kết nối từ xa từ điện thoại (iOS / Android), iPad ra lệnh cho **Antigravity (Gemini)** khi ở quán Cafe / 4G.
2. **`backup_antigravity.py`**:
   - 💾 Công cụ 1-click tự động nén và sao lưu toàn bộ lịch sử chat, database và não bộ của Antigravity thành file `.zip`.
3. **`restore_antigravity.py`**:
   - 🔄 Công cụ 1-click tự động khôi phục dữ liệu từ file `.zip` sang bất kỳ máy tính mới nào.
4. **`start_web_ide.bat`**:
   - 🌐 Khởi động Web IDE Server trên mạng Wi-Fi nội bộ.
5. **`start_remote_tunnel_internet.bat`**:
   - 🌍 Khởi động Microsoft Internet Tunnel.
