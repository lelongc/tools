# DubTab (Live-Dub)

## Tổng quan
**DubTab** là một tiện ích mở rộng Chrome hoàn thiện dùng để dịch và lồng tiếng luồng âm thanh trực tiếp (Live Stream Translator and Dubber). 

## Tính năng & Đặc điểm
- Là một phiên bản nâng cao, kết nối trực tiếp với các dịch vụ Cloud như `Firebase`, `Cloud Functions`, `SonicCaption`, `Posthog`.
- Tích hợp giao diện quản lý lịch sử (`history.html`), xử lý màn hình nền phức tạp (`background.js`, `overlayContent.js`).
- Hoạt động độc lập không cần chạy server local nhờ dựa trên cloud API.
