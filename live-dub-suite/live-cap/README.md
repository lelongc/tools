# Live-Cap

## Tổng quan
**Live-Cap** là một tiện ích mở rộng Chrome chuyên dùng để tạo phụ đề trực tiếp (Live captions) cho bất kỳ âm thanh nào phát ra từ các tab trên trình duyệt.

## Tính năng chính
- **Tab Capture**: Thu thập âm thanh đang phát.
- **Xử lý qua API**: Sử dụng API của Groq (`https://api.groq.com/`) để tận dụng tốc độ xử lý ngôn ngữ siêu nhanh, chuyển đổi giọng nói thành văn bản.
- **Hiển thị Overlay**: Nhúng trực tiếp phụ đề lên trên trang web thông qua content script (`caption.js` và `caption.css`).
